# Google Photos - Bulk Trash

This comes from a personal need where I was moving away from Google Photos and needed a way to quickly move all my photos to the trash. So I created this script and decided to make it public. It wipes everything (at the moment that's all it does).

Any Chromium browser should work.

If you have any other needs, questions or feedback - feel free to reach out.


_Not affiliated with Google. Automates the web UI of your own account; use at your own risk and in line with Google's Terms of Service._
